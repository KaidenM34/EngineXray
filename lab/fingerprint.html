Device fingerprinting

Cookies can be cleared. A fingerprint can't: it's built from tiny differences in how your device draws, plays sound and reports its hardware. This page runs the classic techniques from one script, fp.js.

Planted on this page

  • Canvas fingerprint: draw text and shapes, read the pixels back
  • Font probing: measure the same text in 60 fonts to see which you have
  • GPU model via WebGL's debug renderer info
  • Audio fingerprint via an OfflineAudioContext
  • Hardware details: CPU cores, memory, plugins

Try it

  1. Click the EngineX-ray bookmark, open the Security tab, and click Watch this page.
  2. Click the red button.
  3. EngineX-ray names fp.js as fingerprinting you, with the list of techniques.
