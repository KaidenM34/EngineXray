Secrets

Leaky login app

A pretend app that "logged you in" and made the mistakes real apps make. Anything here that page scripts can read, an XSS bug or a bad third-party script can steal too.

Planted on this page

  • A login token (JWT) in localStorage whose algorithm is none: no signature, so it can be forged
  • An opaque access_token in localStorage
  • A session cookie without HttpOnly, so scripts can read it
  • An AWS access key ID in the page's config script (AWS's own documentation example key)
  • A Stripe test secret key and a Google API key in a page variable (made-up values)
