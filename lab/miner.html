Hidden miner

A real browser miner borrows your CPU to earn cryptocurrency for someone else. This page fakes every sign of one, without mining anything.

Planted on this page

  • fake-miner.wasm with Keccak round constants, the AES S-box and BLAKE-256 values: the CryptoNight recipe
  • Miner function names and a pool address inside that file
  • One web worker per CPU core, the way miners use the whole processor
  • A WebSocket to a fake pool that sends login and receives a job (the stratum protocol)

Try it

  1. Click the EngineX-ray bookmark. The Security tab already flags the wasm file.
  2. In the Security tab, click Watch this page.
  3. Click the red button. Watch the pool connection and worker swarm show up.
